# Product Service (`product-service`)

A Node.js Express microservice running inside Docker and deployed to Kubernetes.

---

## 📋 Prerequisites

Before running this service, ensure you have the following installed:

* **[Node.js](https://nodejs.org/)** (v20 or higher)
* **[Docker Desktop](https://www.docker.com/products/docker-desktop/)** (running on Windows / macOS)
* **[kubectl](https://kubernetes.io/docs/tasks/tools/)** (optional, for local Kubernetes deployment)
